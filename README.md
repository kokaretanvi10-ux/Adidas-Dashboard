📊 Adidas Sales Analysis Dashboard (Excel)

🔍 Project Overview

This project showcases an interactive Excel Dashboard built using Adidas sales data. The dashboard converts raw data into meaningful insights using Excel’s data analysis and visualization capabilities.

The dataset contains 9,600+ records, covering multiple regions, products, and sales channels.

📷 Dashboard Preview - https://www.linkedin.com/feed/update/urn:li:activity:7468940880155000832/


🎯 Objectives

    •	Analyze overall sales and profitability performance 
    
    •	Identify top-performing regions, cities, and retailers 
    
    •	Evaluate product-wise sales trends 
    
    •	Compare sales channels (Online vs In-store)
    
    •	Track operating profit and margin efficiency 
    

📁 Dataset Description

The dataset includes the following fields:

    •	Retailer & Retailer ID 
    
    •	Invoice Date 
    
    •	Region, State, City
    
    •	Product Category
    
    •	Price per Unit 
    
    •	Units Sold 
    
    •	Total Sales
    
    •	Operating Profit 
    
    •	Operating Margin 
    
    •	Sales Method

📈 Key Insights

    •	Some regions contribute significantly higher sales, indicating strong demand 
    
    •	Certain product categories dominate revenue generation 
    
    •	Sales performance varies across retailers, highlighting improvement areas 
    
    •	Profit margins differ across sales channels and products 
    

🚀 How to Use

    1.	Download the Excel file (.xlsx) from this repository 
    
    2.	Open it in Microsoft Excel (2016 or later recommended) 
    
    3.	Use slicers and filters to interact with the dashboard 


📌 Conclusion

This Excel dashboard provides a clear, interactive, and data-driven view of Adidas sales performance. It helps in identifying trends, improving decision-making, and optimizing business strategies.
